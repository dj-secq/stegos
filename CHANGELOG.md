# Changelog

## Unreleased

- `./install-local.sh` and `./start-local.sh` run the bench on Debian, Ubuntu, and Linux Mint without Docker.
- A finished or deleted job no longer leaves the queue full. A refresh shows the analysis that is still running.
- Quick and Deep are two equal choices, and check statuses use plain words.
- Each check lists its leads and quotes the line or the file offset.
- Hex, base64, base32, percent-encoding, and HTML entities are kept when they decode to text. File Profile names UTF-8, UTF-16, UTF-32, or binary. Strings also reads UTF-16 BE.
- A program outside `/usr/local/bin:/usr/bin:/bin` reports unavailable.
- `docs/samples/cat_tails.png` is included, with screenshots in the README.

## 0.2.0

- Standalone repository. The service listens on 127.0.0.1:8786.
- Inspection bench: one stage, a lead rail, and a check list.
- Bit-plane artifacts carry `channel` and `bit`.
- jsteg, jpseek, OpenStego, and pdfid report `unavailable` when the program is absent.
- Waveform, and one spectrogram for each of the first two audio channels.
- Zero-width and unusual-space text checks.
- GIF frame list with delays, capped at 32 frames.
